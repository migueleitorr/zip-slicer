Deploy Zip Slicer to GitHub Pages & Privacy Architecture

🔒 100% Local Browser Processing (Zero Server Upload)

TSF (Technical Support File) archives often contain confidential customer logs, network captures, and configuration state. Zip Slicer has no backend server, no analytics, and performs zero network requests when processing files. It reads only the ZIP Central Directory at the end of the file and uses native Blob.prototype.slice() pointers to package standalone .zip parts directly in browser memory.

How to Host on GitHub Pages in 60 Seconds:

  1. Click the "Download index.html" button in the top-right header of this app.
  2. Create a new GitHub repository (e.g., zip-slicer) and upload index.html to the root of the main branch.
  3. In your GitHub repository, navigate to Settings → Pages, set Source to Deploy from a branch (main / /root), and click Save.
  4. Share your live URL (https://<your-org>.github.io/zip-slicer/) with colleagues!
